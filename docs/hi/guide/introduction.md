# Lingua क्या है?

Lingua एक **Laravel पैकेज** है बहुभाषी प्रबंधन के लिए। यह हर अनुवाद आपके डेटाबेस में संग्रहीत कर सकता है और [Livewire 4](https://livewire.laravel.com) तथा [Flux 2](https://fluxui.dev) पर निर्मित एक सुंदर, रिएक्टिव प्रबंधन UI प्रदान करता है — या, यदि आप चाहें, तो उसी UI का उपयोग करते हुए साधारण `lang/` फ़ाइलों के साथ काम करना जारी रखें।

::: tip 2.0 में नया
संस्करण 2.0 बाहरी `spatie/laravel-translation-loader` और `laravel-lang/common` निर्भरताओं को पूरी तरह से हटाता है, एक प्लगेबल [स्टोरेज ड्राइवर](/hi/guide/storage) सिस्टम (database **या** file) जोड़ता है, एक [Transfer](/hi/guide/quick-start) आयात/निर्यात वर्कफ़्लो, और एक व्यापक [सुरक्षा हार्डनिंग पास](/hi/guide/security)। यह बॉक्स से बाहर सुरक्षित है।
:::

## यह किस समस्या को हल करता है

मानक Laravel अनुवाद `lang/` के अंदर PHP और JSON फ़ाइलों में रहते हैं। यह छोटी परियोजनाओं के लिए अच्छा काम करता है, लेकिन जैसे-जैसे एक एप्लिकेशन बढ़ती है यह घर्षण पैदा करता है:

- **अनुवाद अपडेट करने के लिए एक डिप्लॉयमेंट की आवश्यकता होती है** — यहाँ तक कि एक साधारण टाइपो ठीक करने के लिए भी।
- **गैर-तकनीकी टीम सदस्य अनुवाद संपादित नहीं कर सकते** — संपादकों को Git और कोड रिव्यू की आवश्यकता होती है।
- **अनुवाद पूर्णता को ट्रैक करना मैन्युअल है** — अंतराल खोजने के लिए फ़ाइलों को diff करना होता है।
- **कई लोकेल का समर्थन करना कोडबेस को अव्यवस्थित करता है** — दर्जनों फ़ाइलें निर्देशिकाओं में बिखरी हुई।

डिफ़ॉल्ट **database ड्राइवर** के साथ, Lingua हर अनुवाद को प्रति पंक्ति एकल JSON कॉलम में संग्रहीत करता है और एक Livewire UI प्रदान करता है जहाँ कोई भी अधिकृत उपयोगकर्ता वास्तविक समय में भाषाओं और स्ट्रिंग का प्रबंधन कर सकता है।

## यह कैसे काम करता है — संक्षेप में

```
┌─────────────────────────────────────────────────────────┐
│                   Laravel Application                     │
│                                                           │
│  lang/en/messages.php  ──┐                                │
│  lang/fr/messages.php    │  lingua:sync-to-database       │
│  lang/en.json            ├──────────────────────────────►│
│  lang/vendor/…           │                                │
│                         ─┘   language_lines (DB)          │
│                              ┌──────────────────────┐     │
│  LinguaManager (DB driver) ◄ │ group │ key │ text   │     │
│  app()->setLocale()          │ auth  │ … │ {"en":…} │     │
│                              └──────────────────────┘     │
│  __('auth.failed')  ─────────────────────────────────────►│
│  (DB takes precedence over files)                         │
└─────────────────────────────────────────────────────────┘
```

रनटाइम पर, Lingua का `LinguaManager` Laravel के स्वयं के `Illuminate\Translation\FileLoader` को एक्सटेंड करता है और ट्रांसलेशन लोडर के रूप में पंजीकृत होता है। **database मोड** में यह `array_replace_recursive` के साथ फ़ाइल-आधारित और डेटाबेस अनुवादों को मर्ज करता है — **डेटाबेस एंट्री हमेशा प्राथमिकता लेती हैं** — इसलिए आप स्रोत फ़ाइलों को छुए बिना किसी भी स्ट्रिंग को ओवरराइड कर सकते हैं। **file मोड** में यह मानक Laravel लोडर की तरह व्यवहार करता है, उसी UI द्वारा समर्थित।

## मुख्य अवधारणाएं

| अवधारणा | विवरण |
|---|---|
| **स्टोरेज ड्राइवर** | `database` (डिफ़ॉल्ट) या `file` — देखें [Storage Drivers](/hi/guide/storage) |
| **भाषा** | मेटाडेटा के साथ एक इंस्टॉल किया हुआ लोकेल (नाम, नेटिव नाम, दिशा, सॉर्ट ऑर्डर, डिफ़ॉल्ट फ्लैग) |
| **अनुवाद** | `language_lines` में एक पंक्ति जिसमें `group`, `key`, `type`, और एक JSON `text` कॉलम है जिसमें सभी लोकेल मान हैं |
| **अनुवाद प्रकार** | `text`, `html`, या `markdown` — निर्धारित करता है कि UI में कौन सा संपादक दिखाया जाए (केवल database ड्राइवर) |
| **वेंडर अनुवाद** | एक तृतीय-पक्ष पैकेज से संबंधित अनुवाद; आकस्मिक हटाने से सुरक्षित |
| **डिफ़ॉल्ट लोकेल** | प्राथमिक भाषा; डिफ़ॉल्ट लोकेल के लिए अनुवाद हटाने से पूरा रिकॉर्ड हट जाता है |
| **Sync** | स्थानीय फ़ाइलें → DB आयात करना (`sync-to-database`) या DB → फ़ाइलें निर्यात करना (`sync-to-local`) |

## आवश्यकताएं

| निर्भरता | संस्करण |
|---|---|
| PHP | **8.3+** |
| Laravel | **11 \| 12 \| 13** |
| Livewire | **4.1+** |
| Livewire Flux | **2.12+** |

::: tip कोई बाहरी ट्रांसलेशन लोडर नहीं
Lingua 2.0 की Spatie या laravel-lang पर **कोई** रनटाइम निर्भरता नहीं है। लोकेल मेटाडेटा (129+ लोकेल) और बंडल ट्रांसलेशन डेटासेट (26 लोकेल × 7 ग्रुप, 5902 स्ट्रिंग, Laravel v13.14.0 के अनुरूप) पैकेज के अंदर ही शिप होते हैं — इंस्टॉल के समय कोई GitHub डाउनलोड नहीं।
:::
