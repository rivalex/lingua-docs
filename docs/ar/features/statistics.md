# إحصائيات الترجمة

تمنحك صفحة الإحصائيات نظرة عامة فورية على تغطية ترجماتك عبر جميع
اللغات المثبتة.

<Screenshot src="/screenshots/statistics-page.png" alt="صفحة إحصائيات الترجمة" caption="تعرض صفحة الإحصائيات التغطية لكل لغة وتفصيل المجموعات والمفاتيح الناقصة." />

## نظرة عامة

تعرض الصفحة ثلاثة عدادات ملخصة في الأعلى:

- **إجمالي المفاتيح** — العدد الإجمالي لسلاسل الترجمة
- **إجمالي المجموعات** — عدد مجموعات الترجمة المتميزة
- **اللغات المثبتة** — عدد اللغات في النظام

يمكنك تفعيل **تضمين ترجمات المورّد** لتضمين أو استبعاد ترجمات الحزم
من جميع الإحصائيات.

---

## التغطية حسب اللغة

لكل لغة مثبتة:

| العمود | الوصف |
|---|---|
| اللغة | اسم اللغة وعلمها |
| التغطية | شريط تقدم مع نسبة الاكتمال |
| مترجمة | عدد المفاتيح التي لها قيمة لهذه اللغة |
| ناقصة | عدد المفاتيح بلا قيمة — انقر للتعمق |

**اللغة الافتراضية** تُبرز بشارة وتُظهر دائماً تغطية 100%
(لأنها تُشكِّل مجموعة المفاتيح المرجعية).

---

## التعمق في المفاتيح الناقصة

انقر على **شارة العدد الناقص** في أي صف لغة لتوسيع لوحة المفاتيح
الناقصة في السطر نفسه.

يُظهر كل صف في اللوحة:

- **المجموعة** — مثل `validation`، `auth`
- **المفتاح** — مثل `required`، `failed`
- رابط **ترجمة ←** يفتح صفحة الترجمات مع تطبيق فلتر مسبق لتلك اللغة

انقر على صف اللغة نفسه مرة أخرى لطي اللوحة.

---

## التفصيل حسب المجموعة

جدول التفصيل يسرد كل مجموعة ترجمة مع عدد المفاتيح المترجمة لكل
لغة مثبتة. استخدمه لتحديد المجموعات المترجمة بالكامل والمجموعات التي
تحتاج إلى اهتمام.

---

## تبديل ترجمات المورّد

بشكل افتراضي، تُستبعد ترجمات المورّد من الإحصائيات. فعِّل
**تضمين ترجمات المورّد** لإدراجها.

::: info
ترجمات المورّد غالباً تُصان من قِبَل مؤلف الحزمة. إدراجها قد
يُخفِّض تغطيتك الظاهرة إذا لم تضف تجاوزات خاصة باللغة.
:::

::: tip
رتِّب حسب العدد الناقص لتحديد أولويات جهود الترجمة — اللغات ذات
أكبر عدد من المفاتيح الناقصة تحتاج أكبر قدر من الاهتمام.
:::

---

## الوصول البرمجي

```php
use Rivalex\Lingua\Facades\Lingua;

// Stats for one locale
$stats = Lingua::getLocaleStats('fr');
// ['total' => 1240, 'translated' => 980, 'missing' => 260, 'percentage' => 79.03]

// All languages with stats
$languages = Lingua::languagesWithStatistics();
foreach ($languages as $lang) {
    echo "{$lang->name}: {$lang->completion_percentage}%";
}
```

في **محرك الملفات**، الإحصائيات تُحسَب من عدد المفاتيح في ملفات `lang/`
عبر `TranslationRepository` — لا قاعدة بيانات.
