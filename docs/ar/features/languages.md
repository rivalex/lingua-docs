# إدارة اللغات

صفحة اللغات هي مركز تحكم التعدد اللغوي. من هنا تُضيف اللغات وتُزيلها
وتُرتِّبها وتُزامنها.

## شريط الأدوات

يحتوي شريط الأدوات على صفين:

**الصف الأول: البحث والإضافة**
- **حقل البحث** — يُصفِّي قائمة اللغات فوراً بالاسم أو الرمز
- **زر اللغة الجديدة** — يفتح نافذة لإضافة لغة من السجل المدمج (129+ لغة)
- **ترتيب الفرز** — يُغيِّر ترتيب عرض اللغات

**الصف الثاني: عناصر تحكم المزامنة**
- **مزامنة إلى قاعدة البيانات** — يستورد ملفات `lang/` المحلية إلى قاعدة البيانات
- **مزامنة إلى الملفات المحلية** — يُصدِّر ترجمات قاعدة البيانات إلى `lang/`
- **تحديث اللغات** — يُحدِّث الترجمات المدمجة من مجموعة البيانات الداخلية

## إضافة لغة

### عبر معالج الأوامر

```bash
php artisan lingua:add {locale}
# أمثلة:
php artisan lingua:add fr
php artisan lingua:add pt_BR ar zh
```

### عبر الواجهة

1. انقر **اللغة الجديدة** في شريط أدوات صفحة اللغات
2. ابدأ كتابة اسم اللغة أو رمزها في حقل البحث
3. اختر من القائمة المُعبَّأة من السجل المدمج
4. انقر **إضافة**

تُبذَر الترجمات المدمجة (إن وُجدت لهذه اللغة) تلقائياً في قاعدة
البيانات — **بدون استدعاءات شبكة أو تنزيلات**.

### برمجياً

```php
use Rivalex\Lingua\Facades\Lingua;

// Check what's not yet installed
$available = Lingua::notInstalled(); // ['af', 'ar', 'az', …]

// Get locale info
$info = Lingua::info('fr'); // ?LocaleInfo
```

## إزالة لغة

::: danger الإزالة دائمة
إزالة لغة يحذف **جميع** سجلات الترجمة لتلك اللغة من عمود JSON
في `language_lines`. لا يمكن التراجع عن هذا. صدِّر الترجمات أولاً
إذا أردت الاحتفاظ بنسخة.
:::

لإزالة لغة:
1. مرِّر الماوس فوق اللغة في القائمة
2. انقر أيقونة الحذف
3. أكِّد في نافذة الحوار

**اللغة الافتراضية لا يمكن حذفها** — يجب تعيين لغة افتراضية أخرى أولاً.

```bash
# From the command line
php artisan lingua:remove fr
```

---

## تعيين اللغة الافتراضية

اللغة الافتراضية هي القاعدة: حذف ترجمة اللغة الافتراضية يحذف السجل
بالكامل؛ اللغات الأخرى تترك سجلاً مع قيمة مفقودة.

لتغيير اللغة الافتراضية:
1. انقر أيقونة النجمة بجانب أي لغة
2. تُحدَّث علامة "الافتراضي" فوراً

```php
// Programmatically
Lingua::setDefaultLocale('fr');
```

## إعادة ترتيب اللغات

اسحب اللغات وأفلتها لإعادة ترتيبها. يُحدَّث عمود `sort` في `languages`
فوراً. هذا الترتيب يؤثر على:

- ترتيب ظهور اللغات في محدد اللغة (`x-lingua::select`)
- ترتيب الأعمدة في تصدير CSV متعدد اللغات

## إحصاءات الاكتمال

يعرض كل صف لغة شريط تقدم وعدادَين:

| المقياس | الوصف |
|---|---|
| **إجمالي السلاسل** | إجمالي السجلات في `language_lines` |
| **المترجمة** | السجلات التي لها قيمة غير فارغة لهذه اللغة |
| **نسبة الاكتمال** | (مترجمة / إجمالي) × 100 |

في **محرك الملفات**، تُقرأ هذه الإحصائيات من عدد المفاتيح في ملفات `lang/`
مباشرةً عبر `TranslationRepository`.

```php
// Get stats for a specific locale
$stats = Lingua::getLocaleStats('fr');
// ['total' => 1240, 'translated' => 980, 'missing' => 260, 'percentage' => 79.03]
```

## عناصر تحكم المزامنة

### مزامنة إلى قاعدة البيانات

```bash
php artisan lingua:sync-to-database
```

يستورد ملفات `lang/` المحلية إلى `language_lines`. مفيد عند:
- الانتقال من محرك `file` إلى `database`
- بعد إضافة ملفات لغة يدوياً

### مزامنة إلى الملفات المحلية

```bash
php artisan lingua:sync-to-local
```

يُصدِّر جميع سجلات `language_lines` إلى ملفات `lang/` بتنسيق PHP+JSON.

### تحديث اللغات

```bash
php artisan lingua:update-lang
```

يُحدِّث الترجمات **المدمجة فقط** (مجموعات `auth`، `validation`، إلخ) من
مجموعة البيانات الداخلية لـ Lingua. **لا يُلمس** ترجماتك المخصصة.

::: tip
جميع عمليات المزامنة تستخدم الإلغاء الدقيق للتخزين المؤقت — فقط
مفاتيح `(locale, group)` المتأثرة تُنسى، لا `cache:clear` عام.
:::
