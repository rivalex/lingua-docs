# النقل (استيراد / تصدير)

<Badge type="tip" text="جديد في 2.0" /> صفحة النقل تُمكِّنك من تصدير الترجمات
إلى ملفات جاهزة للتسليم إلى وكالة ترجمة أو جدول بيانات، ثم
استيراد الترجمات المُعدَّلة مرة أخرى — مع معاينة فرق كاملة قبل
الحفظ.

---

## الصيغ المدعومة

| الصيغة | التصدير | الاستيراد | الشرط |
|---|---|---|---|
| CSV | ✓ | ✓ | مدمج |
| JSON | ✓ | ✓ | مدمج |
| XLSX | ✓ | ✓ | `openspout/openspout` |
| ODS | ✓ | ✓ | `openspout/openspout` |

CSV وJSON يعملان افتراضياً. لتفعيل XLSX/ODS:

```bash
composer require openspout/openspout
```

## التصدير

### نطاقات التصدير

| النطاق | الوصف |
|---|---|
| **ثنائي اللغة** | لغة المصدر + لغة هدف واحدة. مثالي للإرسال إلى المترجم. |
| **متعدد اللغات** | جميع اللغات أو مجموعة منها في ملف واحد. |
| **JSON الأصلي** | تصدير مفاتيح JSON المسطّحة — مناسب لتكامل مشاريع أخرى. |

### خيارات التصدير

- **المجموعة** — تصدير مجموعة واحدة (`auth`، `validation`، إلخ) أو الكل
- **اللغة المصدر** — القيم المرجعية (عادةً `en`)
- **اللغة الهدف** / اللغات — اللغة/اللغات المطلوب ترجمتها

```
/lingua/transfer → انقر "تصدير" → اختر النطاق والصيغة → تنزيل
```

يُنشأ الملف وينزل مباشرةً — بدون تخزين مؤقت في الخادم.

## الاستيراد

### سير عمل الاستيراد (خطوتان)

#### الخطوة 1 — رفع الملف

1. انتقل إلى `/lingua/transfer` وانقر **استيراد**
2. ارفع الملف (CSV، JSON، XLSX، أو ODS)
3. تُحلِّل Lingua الملف وتستنتج الصيغة والبنية تلقائياً

#### الخطوة 2 — مراجعة الفرق والتأكيد

قبل كتابة أي شيء، تُعرض **معاينة فرق جافة**:

```
┌─────────────────────┬─────────────────────┬──────────────────┐
│ المفتاح             │ القيمة الحالية      │ القيمة الجديدة   │
├─────────────────────┼─────────────────────┼──────────────────┤
│ auth.failed         │ بيانات اعتماد خاطئة │ معلومات تسجيل …  │
│ auth.throttle       │ (مفقودة)           │ حاولت كثيراً …   │
│ validation.required │ الحقل مطلوب         │ (لا تغيير)       │
└─────────────────────┴─────────────────────┴──────────────────┘
```

- الأخضر → إضافات جديدة
- الأصفر → تحديثات على قيم موجودة
- الرمادي → لا تغيير (لن تُكتب)

**لن تتغير أي بيانات حتى تنقر "تأكيد الاستيراد".**

## الضمانات والحماية

### حماية المورّد

الترجمات المُعلَّمة بـ `is_vendor = true` **لا يمكن استبدالها** عبر
الاستيراد. إذا كان الملف المستورد يحتوي على مفتاح مورّد، يُتخطى الصف
وتظهر تحذير في ملخص النتائج.

### رفض بدل المجموعة

الاستيراد يرفض المفاتيح التي تستخدم أحرف بدل (`*`، `%`).

### أسبقية النوع

| الحالة | النتيجة |
|---|---|
| مفتاح موجود بنوع `html` | يُحافظ على نوع `html` عند الاستيراد |
| مفتاح جديد في الاستيراد | يُنشأ بنوع `text` افتراضياً |
| تعارض نوع في XLSX | نوع الصف الموجود يسود |

### معالجة الأخطاء

إذا فشل صف واحد (نوع بيانات خاطئ، مفتاح مرفوض):

- الاستيراد **يستمر** للصفوف الأخرى (لا عملية ذرية للاستيراد)
- الصفوف الفاشلة تُدرج في قسم `$rowErrors` في ملخص النتائج

## الاستيراد عبر الكود

```php
use Rivalex\Lingua\Services\Import\ImportDiffService;
use Rivalex\Lingua\Services\Import\ImportCommitService;

// Preview diff
$diff = app(ImportDiffService::class)->diff($rows, $targetLocale);

// Commit
app(ImportCommitService::class)->commit($diff, $targetLocale);
```

## القيود

- صفحة النقل متاحة فقط مع **محرك `database`** — استخدم أوامر Artisan
  لمزامنة الملفات في محرك `file`.
- الاستيراد الكبير (أكثر من 10000 صف) يُوصى بتشغيله عبر واجهة Artisan
  أو طابور الوظائف لتجنب انتهاء المهلة.
