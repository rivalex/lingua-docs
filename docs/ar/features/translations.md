# إدارة الترجمات

صفحة الترجمات هي المكان الذي تُحرِّر فيه السلاسل النصية. تدعم التحرير
المضمَّن لجميع أنواع الترجمة، مع محرر نص غني كامل لأنواع HTML وMarkdown.

## التخطيط

```
[شريط الأدوات: بحث | مجموعة | نوع | ناقصة فقط | ترقيم]
┌─────────────┬──────────────────────┬─────────────────────┐
│  المفتاح    │  اللغة الافتراضية    │  اللغة الهدف        │
├─────────────┼──────────────────────┼─────────────────────┤
│ auth.failed │  Wrong credentials   │  بيانات اعتماد خاطئة│
│ auth.throttle│  Too many attempts  │  (ناقصة)            │
└─────────────┴──────────────────────┴─────────────────────┘
```

---

## شريط الأدوات

| العنصر | الوصف |
|---|---|
| **البحث** | يُصفِّي الصفوف حسب مفتاح الترجمة أو قيمتها |
| **المجموعة** | يُصفِّي حسب مجموعة الترجمة (`auth`، `validation`، `single`، إلخ) |
| **النوع** | يُصفِّي حسب `text` أو `html` أو `markdown` |
| **لغة العرض** | يُغيِّر اللغة الهدف المعروضة في العمود الأيمن |
| **الناقصة فقط** | يُظهر فقط الصفوف التي تفتقر إلى ترجمة في اللغة الهدف |
| **ترقيم الصفحات** | 25 / 50 / 100 صف لكل صفحة |

---

## التحرير المضمَّن

انقر على أي خلية في عمود اللغة الهدف لتحريرها مباشرةً:

- **نوع `text`**: حقل `<textarea>` بسيط
- **نوع `html`**: محرر TipTap بشريط أدوات (جريء، مائل، روابط، إلخ)
- **نوع `markdown`**: محرر TipTap مع التبديل إلى وضع الكود الخام

احفظ بـ `Tab` أو فقدان التركيز. أغلق بـ `Esc`. التغييرات تنعكس فوراً.

<Screenshot src="/screenshots/translations-page.png" alt="صفحة الترجمات في Lingua" caption="صفحة الترجمات - مع محوِّل اللغة وتصفية المجموعة والمحرر المضمّن." />

::: tip محرك الملفات
في محرك `file`، التحرير المضمَّن يكتب مباشرةً إلى ملفات `lang/` على
القرص وينسخ PHP opcache فور الكتابة. أنواع HTML/Markdown غير متاحة.
:::

## اختصارات لوحة المفاتيح

| الاختصار | الإجراء |
|---|---|
| `Tab` | حفظ والانتقال إلى الخلية التالية |
| `Shift+Tab` | حفظ والانتقال إلى الخلية السابقة |
| `Esc` | إلغاء التعديل وإغلاق المحرر |

## إنشاء ترجمة جديدة

انقر **ترجمة جديدة** في شريط الأدوات وأدخل:

- **المجموعة** — مثل `messages` أو `emails` (أو `single` للملفات JSON)
- **المفتاح** — مثل `welcome` أو `order.confirm.subject`
- **النوع** — `text`، `html`، أو `markdown`
- **القيمة** للغة الافتراضية (اختياري)

المفتاح الجديد متاح فوراً عبر `__('messages.welcome')`.

::: tip
حقل **المجموعة** يُحتفظ به بعد الإنشاء لتسهيل إضافة مفاتيح متعددة
للمجموعة ذاتها. المسافات الزائدة في المجموعة والمفتاح تُعالج تلقائياً.
:::

## حذف ترجمة

**سلوك الحذف حسب العرض:**

- حذف في **عرض اللغة الافتراضية** → يحذف السجل بأكمله (جميع اللغات)
- حذف في **عرض لغة أخرى** → يُزيل فقط قيمة تلك اللغة من عمود JSON

**سلاسل المورّد** لا يمكن حذفها — حارس F5 يمنع ذلك ويعرض
رسالة خطأ.

---

## تغيير نوع الترجمة

لتغيير النوع (`text` ↔ `html` ↔ `markdown`):

1. انقر أيقونة القلم في عمود اللغة الافتراضية
2. غيِّر النوع في نافذة التعديل
3. احفظ

::: warning النوع مشترك بين اللغات
النوع ينطبق على **السجل بأكمله**. تغييره يؤثر على كيفية عرض المحرر
لجميع اللغات. القيمة المخزَّنة لا تتغير.
:::

---

## نسخ مفتاح الترجمة

كل صف يحتوي على أيقونة حافظة تنسخ مرجع `group.key` الكامل
(مثل `auth.failed`) — مفيد عند الإشارة إلى المفاتيح في Blade أو PHP.

## ترجمات المورّد

ترجمات الحزم الخارجية مُعلَّمة بـ `is_vendor = true`. يمكنك **تعديلها**
لكن **لا يمكن حذفها** — راجع [ترجمات المورّد](/ar/features/vendor-translations).
