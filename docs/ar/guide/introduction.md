# ما هو Lingua؟

Lingua هي **حزمة Laravel** لإدارة التعدد اللغوي. يمكنها تخزين
كل ترجمة في قاعدة البيانات وتأتي مع واجهة إدارة تفاعلية وأنيقة
مبنية على [Livewire 4](https://livewire.laravel.com) و
[Flux 2](https://fluxui.dev) — أو، إذا كنت تفضل ذلك، استمر في العمل مع ملفات
`lang/` العادية مع استخدام نفس الواجهة.

::: tip جديد في 2.0
الإصدار 2.0 يُزيل الاعتماديات الخارجية `spatie/laravel-translation-loader` و
`laravel-lang/common` بالكامل، ويضيف نظام
[محركات التخزين](/ar/guide/storage) القابل للتوصيل (قاعدة البيانات **أو** الملفات)، وسير عمل
[النقل](/ar/guide/quick-start) للاستيراد/التصدير، ومرحلة
[تصليب شاملة للأمان](/ar/guide/security). هو آمن افتراضياً.
:::

## المشكلة التي تحلها

ترجمات Laravel القياسية مخزّنة في ملفات PHP وJSON داخل `lang/`.
يعمل هذا بشكل جيد للمشاريع الصغيرة، لكنه يُسبِّب احتكاكًا مع نمو
التطبيق:

- **تحديث الترجمة يتطلب نشراً** — حتى لإصلاح خطأ مطبعي بسيط.
- **أعضاء الفريق غير التقنيين لا يمكنهم تعديل الترجمات** — يحتاج المحررون
  إلى Git ومراجعة الكود.
- **تتبع اكتمال الترجمة يدوي** — يجب مقارنة الملفات لإيجاد الثغرات.
- **دعم لغات متعددة يُعقِّد قاعدة الكود** — عشرات الملفات مبعثرة عبر مجلدات.

مع **محرك قاعدة البيانات** الافتراضي، تخزّن Lingua كل ترجمة في
عمود JSON واحد لكل صف وتوفر واجهة Livewire حيث يمكن لأي مستخدم مخوَّل
إدارة اللغات والنصوص في الوقت الفعلي.

## كيف تعمل باختصار

```
┌─────────────────────────────────────────────────────────┐
│                   Laravel Application                     │
│                                                           │
│  lang/en/messages.php  ──┐                                │
│  lang/fr/messages.php    │  lingua:sync-to-database       │
│  lang/en.json            ├──────────────────────────────►│
│  lang/vendor/…           │                                │
│                         ─┘   language_lines (DB)          │
│                              ┌──────────────────────┐     │
│  LinguaManager (DB driver) ◄ │ group │ key │ text   │     │
│  app()->setLocale()          │ auth  │ … │ {"en":…} │     │
│                              └──────────────────────┘     │
│  __('auth.failed')  ─────────────────────────────────────►│
│  (DB takes precedence over files)                         │
└─────────────────────────────────────────────────────────┘
```

في وقت التشغيل، يمتد `LinguaManager` الخاص بـ Lingua من
`Illuminate\Translation\FileLoader` الخاص بـ Laravel ويُسجَّل كمحمّل ترجمة.
في **وضع قاعدة البيانات** يدمج الترجمات المستندة إلى الملفات وترجمات قاعدة
البيانات بـ `array_replace_recursive` — **مدخلات قاعدة البيانات تفوز دائماً عند التعارض** —
لذا يمكنك تجاوز أي نص دون لمس ملفات المصدر. في **وضع الملفات** يتصرف
كمحمّل Laravel القياسي، مدعوماً بنفس الواجهة.

## المفاهيم الأساسية

| المفهوم | الوصف |
|---|---|
| **محرك التخزين** | `database` (الافتراضي) أو `file` — انظر [محركات التخزين](/ar/guide/storage) |
| **اللغة** | لغة مثبتة مع بيانات وصفية (الاسم، الاسم الأصلي، الاتجاه، ترتيب الفرز، علامة الافتراضي) |
| **الترجمة** | صف في `language_lines` يحتوي على `group` و`key` و`type` وعمود JSON لـ `text` يحتوي على جميع قيم اللغات |
| **نوع الترجمة** | `text` أو `html` أو `markdown` — يحدد المحرر المعروض في الواجهة (محرك قاعدة البيانات فقط) |
| **ترجمة المورّد** | ترجمة تنتمي إلى حزمة طرف ثالث؛ محمية من الحذف غير المقصود |
| **اللغة الافتراضية** | اللغة الأساسية؛ حذف ترجمة اللغة الافتراضية يحذف السجل بالكامل |
| **المزامنة** | استيراد الملفات المحلية → قاعدة البيانات (`sync-to-database`) أو تصدير قاعدة البيانات → ملفات (`sync-to-local`) |

## المتطلبات

| الاعتمادية | الإصدار |
|---|---|
| PHP | **8.3+** |
| Laravel | **11 \| 12 \| 13** |
| Livewire | **4.1+** |
| Livewire Flux | **2.12+** |

::: tip لا محمّلات ترجمة خارجية
لا يوجد لـ Lingua 2.0 **أي** اعتمادية في وقت التشغيل على Spatie أو laravel-lang. بيانات
اللغات الوصفية (أكثر من 129 لغة) ومجموعة الترجمات المدمجة (26 لغة × 7
مجموعات، 5902 سلسلة نصية، متوافقة مع Laravel v13.14.0) تشحن داخل
الحزمة — بدون تنزيلات من GitHub وقت التثبيت.
:::
