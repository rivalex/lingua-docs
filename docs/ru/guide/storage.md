# Драйверы хранилища

<Badge type="tip" text="Новое в 2.0" /> Lingua 2.0 вводит подключаемую
**систему драйверов хранилища**. Вы выбираете, где хранятся переводы: в
**базе данных** (полнофункциональный вариант по умолчанию) или в обычных **файлах `lang/`**.

```php
// config/lingua.php
'storage' => [
    'driver' => env('LINGUA_STORAGE_DRIVER', 'database'),
],
```

## Выбор драйвера

| Функция | `database` | `file` |
|---|:---:|:---:|
| Хранилище | таблица `language_lines` | `lang/` PHP + JSON |
| Типы HTML / Markdown | ✅ | ❌ (сводятся к простому тексту) |
| Статистика переводов | ✅ | ✅ (вычисляется из файлов) |
| Импорт / экспорт (Transfer) | ✅ | ✅ |
| Защита вендорных переводов | ✅ | ✅ |
| Точечное кеширование по (locale,group) | ✅ | нет |
| Кнопки синхронизации в UI | ✅ | скрыты |
| Редактирование переводов в UI | ✅ | ✅ |

::: tip Правило выбора
Используйте **database** для наиболее богатого функционала и runtime-переопределений. Используйте
**file**, когда переводы должны оставаться под контролем версий или файловая система
является источником истины.
:::

## Драйвер database

По умолчанию, идентичен поведению 1.x.

- Переводы хранятся в таблице `language_lines`, все локали в одном JSON-столбце `text` на строку
- Поддерживает типы `text`, `html` и `markdown`, каждый со своим редактором
- Точечное кеширование: `Cache::forget('lingua.trans.{locale}.{group}')` при каждой записи — без глобального сброса
- Полная статистика, импорт/экспорт и защита вендорных переводов
- Runtime-переопределения превосходят файлы `lang/` через `array_replace_recursive`

## Драйвер file

Читает и записывает PHP и JSON файлы `lang/` напрямую. Таблица `language_lines` **не используется**.

::: danger Потеря типов в режиме file
Драйвер `file` хранит только обычные строки. Типы HTML и Markdown **сводятся к простому тексту** —
редактор с поддержкой типов и метаданные типа недоступны.
Если вы используете переводы HTML/Markdown, используйте database-драйвер.
:::

- Без запросов к БД; работает как стандартный `FileLoader` Laravel
- Кнопки синхронизации **скрыты** в UI (файлы *являются* хранилищем)
- `lingua:sync-to-local` **ничего не делает без `--force`** (БД, из которой был бы экспорт, не является активным хранилищем)
- Правки в UI записываются напрямую в файлы через `AtomicFileWriter`
  (атомарное переименование + `opcache_invalidate` — см.
  [Безопасность](/ru/guide/security#file-mode-security))

::: warning Предостережение для деплоя
На платформах, которые восстанавливают `lang/` из репозитория при каждом деплое
(например, Forge, Envoyer, образы контейнеров), правки UI в режиме file могут быть
**перезаписаны** при следующем деплое. Фиксируйте изменения в репозитории или
используйте database-драйвер.
:::

## Переключение драйверов

Используйте команду `lingua:storage` для переключения в любое время. Она **синхронизирует перед переключением**,
чтобы ничего не было потеряно.

```bash
php artisan lingua:storage file
php artisan lingua:storage database
```

| Флаг | Действие |
|---|---|
| `--force` | Пропустить запросы подтверждения |
| `--write-env` | Обновить `LINGUA_STORAGE_DRIVER` в `.env` |
| `--no-migrate` | Пропустить шаг обеспечения миграции |

### Database → file

Lingua сначала **экспортирует** базу данных в `lang/`, предупреждая о строках HTML/Markdown,
которые потеряют свой тип, затем переключает активный драйвер.

### File → database

Lingua **синхронизирует** `lang/` в базу данных и убеждается, что миграция
`language_lines` запущена, затем переключает.

## Установка с выбором драйвера

Интерактивный установщик спрашивает, какой драйвер использовать, и публикует
**учитывающие драйвер** миграции — драйвер `file` полностью пропускает миграцию
`language_lines`:

```bash
php artisan lingua:install
```

См. [Установка](/ru/guide/installation).

## Удаление

`lingua:uninstall` безопасно удаляет Lingua:

```bash
php artisan lingua:uninstall
```

Сначала **экспортирует базу данных в `lang/`**, затем удаляет три таблицы Lingua
(`language_lines`, `languages`, `lingua_settings`). Директория `lang/` сохраняется.

| Флаг | Действие |
|---|---|
| `--force` | Пропустить запросы подтверждения |
| `--keep-config` | Оставить `config/lingua.php` на месте |
| `--keep-published` | Оставить опубликованные представления/миграции на месте |

## Прямые запросы (database-драйвер)

```php
use Rivalex\Lingua\Models\Translation;

// Все переводы с французским значением
Translation::whereNotNull('text->fr')->get();

// Только отсутствующие французские переводы
Translation::whereNull('text->fr')->get();

// Конкретный ключ
Translation::where('group', 'validation')->where('key', 'required')->first();
```

См. [Переводы пакетов](/ru/features/vendor-translations) о том, как строки пакетов
защищены в обоих драйверах.
