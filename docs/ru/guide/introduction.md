# Что такое Lingua?

Lingua — это **пакет для Laravel** для многоязычного управления. Он может хранить
все переводы в базе данных и предоставляет красивый реактивный
интерфейс управления, построенный на [Livewire 4](https://livewire.laravel.com) и
[Flux 2](https://fluxui.dev) — или, если вы предпочитаете, продолжайте
работать с обычными файлами `lang/`, используя при этом тот же UI.

::: tip Новое в 2.0
Версия 2.0 полностью удаляет внешние зависимости `spatie/laravel-translation-loader` и
`laravel-lang/common`, добавляет подключаемую
[систему драйверов хранилища](/ru/guide/storage) (database **или** file),
рабочий процесс [Transfer](/ru/guide/quick-start) для импорта/экспорта и
комплексный [пакет мер безопасности](/ru/guide/security). Пакет безопасен
«из коробки».
:::

## Какую проблему он решает

Стандартные переводы Laravel хранятся в PHP и JSON файлах внутри `lang/`.
Это хорошо работает для небольших проектов, но создаёт сложности по мере роста приложения:

- **Обновление перевода требует деплоя** — даже для исправления простой опечатки.
- **Нетехнические члены команды не могут редактировать переводы** — редакторам нужен Git и code review.
- **Отслеживание полноты переводов — ручная работа** — нужно сравнивать файлы, чтобы найти пробелы.
- **Поддержка множества локалей загромождает кодовую базу** — десятки файлов, разбросанных по директориям.

С драйвером **database** (по умолчанию), Lingua хранит все переводы в
единственном JSON-столбце на строку и предоставляет Livewire UI, где любой
авторизованный пользователь может управлять языками и строками в реальном времени.

## Принцип работы

```
┌─────────────────────────────────────────────────────────┐
│                   Laravel Application                     │
│                                                           │
│  lang/en/messages.php  ──┐                                │
│  lang/fr/messages.php    │  lingua:sync-to-database       │
│  lang/en.json            ├──────────────────────────────►│
│  lang/vendor/…           │                                │
│                         ─┘   language_lines (DB)          │
│                              ┌──────────────────────┐     │
│  LinguaManager (DB driver) ◄ │ group │ key │ text   │     │
│  app()->setLocale()          │ auth  │ … │ {"en":…} │     │
│                              └──────────────────────┘     │
│  __('auth.failed')  ─────────────────────────────────────►│
│  (DB takes precedence over files)                         │
└─────────────────────────────────────────────────────────┘
```

Во время выполнения `LinguaManager` от Lingua расширяет собственный
`Illuminate\Translation\FileLoader` Laravel и регистрируется как загрузчик переводов.
В **режиме database** он объединяет файловые и database-переводы с помощью
`array_replace_recursive` — **записи в базе данных всегда имеют приоритет** —
поэтому можно переопределить любую строку без изменения исходных файлов.
В **режиме file** он работает как стандартный загрузчик Laravel, поддерживаемый
тем же UI.

## Ключевые концепции

| Концепция | Описание |
|---|---|
| **Драйвер хранилища** | `database` (по умолчанию) или `file` — см. [Драйверы хранилища](/ru/guide/storage) |
| **Язык** | Установленная локаль с метаданными (название, нативное название, направление, порядок сортировки, флаг по умолчанию) |
| **Перевод** | Строка в `language_lines` с `group`, `key`, `type` и JSON-столбцом `text`, содержащим значения для всех локалей |
| **Тип перевода** | `text`, `html` или `markdown` — определяет, какой редактор отображается в UI (только для database-драйвера) |
| **Перевод пакета (vendor)** | Перевод, принадлежащий стороннему пакету; защищён от случайного удаления |
| **Локаль по умолчанию** | Основной язык; удаление перевода для локали по умолчанию удаляет всю запись |
| **Синхронизация** | Импорт локальных файлов → БД (`sync-to-database`) или экспорт БД → файлы (`sync-to-local`) |

## Требования

| Зависимость | Версия |
|---|---|
| PHP | **8.3+** |
| Laravel | **11 \| 12 \| 13** |
| Livewire | **4.1+** |
| Livewire Flux | **2.12+** |

::: tip Без внешних загрузчиков переводов
Lingua 2.0 **не** имеет runtime-зависимости от Spatie или laravel-lang. Метаданные
локалей (129+ локалей) и встроенный набор переводов (26 локалей × 7 групп, 5902 строки,
соответствует Laravel v13.14.0) поставляются внутри пакета — никаких загрузок с GitHub
во время установки.
:::
