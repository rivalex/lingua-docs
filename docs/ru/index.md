features:
  - icon: 🔒
    title: Без зависимостей
    details: Lingua содержит собственный загрузчик переводов, реестр локалей и встроенный набор данных. Без Spatie, без laravel-lang — ничего лишнего для синхронизации.

  - icon: 🗄️
    title: Два драйвера хранилища
    details: Храните переводы в базе данных (живое редактирование через UI, без деплоев) или в файлах (с контролем версий, удобно для CI). Переключение одной командой.

  - icon: 📤
    title: Импорт / Экспорт
    details: "Перемещайте переводы между форматами: CSV, JSON, XLSX, ODS. Двуязычный, многолокальный или json-native режим. Предварительный просмотр изменений перед применением."

  - icon: 🛡️
    title: Защита безопасности
    details: "Комплексное укрепление F1–F9: XSS-санитайзер, защита от path traversal, запрет SQL-инъекций, защита вендорных переводов, шлюз аутентификации, скрытие деталей ошибок и многое другое."

  - icon: ⚡
    title: Реактивный UI
    details: Пять Livewire-страниц — Languages, Translations, Statistics, Settings и Transfer. Все действия выполняются в реальном времени, деплой для исправления опечаток не нужен.

  - icon: 🌐
    title: 129+ локалей в комплекте
    details: "Устанавливайте любую локаль из встроенного реестра. Без загрузки из интернета. В комплекте: 26 локалей, 5902 строки, соответствует Laravel 13.14."

  - icon: ↔️
    title: Поддержка RTL / LTR
    details: Арабский, иврит, персидский и другие RTL-скрипты полностью поддерживаются. Метаданные о направлении текста хранятся и доступны для каждого языка.

  - icon: 📊
    title: Покрытие переводов
    details: Статистика полноты переводов по каждому языку — общее количество строк, количество переведённых и отсутствующие ключи по группам. Всегда знайте, что ещё нужно перевести.

  - icon: 🧪
    title: 783 теста
    details: PHP 8.3+ · Laravel 12–13 · Livewire 4.1+ · Flux 2.12+. Тестовый набор охватывает команды, компоненты, драйверы, импорт/экспорт и полный API фасада.
