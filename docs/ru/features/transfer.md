# Transfer: Импорт и экспорт

<Badge type="tip" text="Новое в 2.0" /> Страница Transfer (`/lingua/transfer`)
обеспечивает импорт и экспорт переводов между Lingua и внешними форматами файлов.
Используйте её для массового редактирования, отправки файлов переводческим агентствам
или выполнения резервного копирования.

## Поддерживаемые форматы

| Формат | Расширение | Требования |
|---|---|---|
| CSV | `.csv` | встроено |
| JSON | `.json` | встроено |
| XLSX | `.xlsx` | `openspout/openspout` |
| ODS | `.ods` | `openspout/openspout` |

::: tip XLSX/ODS
XLSX и ODS работают только если установлен `openspout/openspout`:
```bash
composer require openspout/openspout
```
Без него кнопки XLSX/ODS заменяются сообщением-подсказкой в UI.
:::

## Экспорт

На вкладке **Export** выберите режим и формат, затем нажмите **Download**.

### Режимы экспорта

| Режим | Структура | Когда использовать |
|---|---|---|
| **Bilingual** | Source + одна целевая локаль на файл | Отправка переводчику одного языка |
| **Multi-locale** | Все локали в одном файле | Обзор или массовое редактирование |
| **JSON native** | Laravel JSON-файлы без изменений | CI/CD конвейеры или git-синхронизация |

### Опции экспорта

- **Source locale** — базовая локаль (обычно `en`)
- **Target locale** — целевая локаль для двуязычного режима
- **Group** — фильтрация по группе (`auth`, `validation`, …) или «все»
- **Include vendor** — включить вендорные строки

## Импорт

На вкладке **Import** загрузите файл, затем просмотрите **diff** перед применением изменений.

### Шаг 1 — Предварительный просмотр diff

После загрузки файла Lingua показывает список изменений:

- **Added** — новые ключи из файла, которых нет в хранилище
- **Updated** — ключи с изменёнными значениями
- **Unchanged** — совпадающие строки (не будут перезаписаны)
- **Skipped** — строки с предупреждениями (вендорные строки, неверный формат и т.д.)

### Шаг 2 — Применение

Нажмите **Commit**, чтобы применить изменения из diff. Операция транзакционна —
при ошибке все изменения откатываются.

## Механизмы защиты

### Защита вендорных переводов

Попытка перезаписать `is_vendor = true` строку через импорт заблокируется — строка
помечается как **Skipped** с указанием причины. Используйте
`Lingua::setVendorTranslation()`, чтобы намеренно переопределить вендорный перевод.

### Сопоставление столбцов заголовков

При импорте CSV/XLSX Lingua сопоставляет заголовки столбцов с локалями по:

1. Точному совпадению кода (`fr`, `pt_BR`)
2. Нечёткому совпадению (`fr - French`, `it_IT`)
3. Для двуязычных файлов с одним столбцом-кандидатом — автоматическое назначение

Неоднозначные столбцы — файлы с ≥ 2 кандидатами без чёткого соответствия — пропускаются
с предупреждением.

### Защита от формульных инъекций

Значения, начинающиеся с `=`, `+`, `-`, `@`, табуляции или возврата каретки,
получают префикс `'` при экспорте в CSV/XLSX и нормализуются обратно при импорте.

### Wildcard-ключи

Ключи, содержащие `*` или нулевой байт, отклоняются при импорте.

## Заметки о драйвере

| Режим | Экспорт | Импорт |
|---|---|---|
| database | Из таблицы `language_lines` | В таблицу `language_lines` через БД-транзакцию |
| file | Из файлов `lang/` | В файлы `lang/` через `AtomicFileWriter` |
