# Управление языками

Страница Languages (`/lingua/languages`) — главная точка управления установленными языками.

## Панель инструментов

Панель инструментов разбита на **две строки**:

**Первая строка** — поиск и создание:
- Поле поиска (фильтрует список по коду, названию или нативному названию языка)
- Кнопка **New Language** (добавить новый язык)

**Вторая строка** — синхронизация:
- **Sync from files** — импортирует `lang/` в базу данных
- **Sync to files** — экспортирует базу данных в `lang/`
- **Update** — загружает последние строки из встроенного набора данных для установленных локалей

::: tip
Кнопки синхронизации скрыты в режиме драйвера `file`, поскольку файлы *являются* хранилищем.
:::

## Добавление языка

### Через UI

Нажмите **New Language** в панели инструментов. Откроется модальное окно с:

- Переключателем быстрого выбора для популярных языков
- Полем поиска (фильтрует 129+ доступных локалей из встроенного реестра)
- Превью нативного названия и кода для каждого варианта

::: tip Только через БД в database-режиме
При добавлении языка через UI или CLI в database-режиме строки заполняются напрямую
из встроенного набора данных — файлы в `lang/` не скачиваются и не создаются.
:::

### Через CLI

```bash
php artisan lingua:add fr
php artisan lingua:add fr de it
```

### Программно

```php
use Rivalex\Lingua\Facades\Lingua;

Lingua::addLanguage('fr');
```

::: warning Изменено в 2.0
`addLanguage()` больше **не** вызывает `lang:add`. Это нативная операция через БД.
:::

## Удаление языка

Нажмите кнопку удаления рядом с любым языком в списке. Lingua попросит подтверждения.

::: danger Каскадное удаление
Удаление языка удаляет **все его переводы** из JSON-столбца `text` в таблице
`language_lines`. Если это язык по умолчанию, сначала назначьте другой.
:::

Программно:

```php
Lingua::removeLanguage('fr');
```

::: warning Изменено в 2.0
`removeLanguage()` больше **не** вызывает `lang:rm`. Только нативная работа с БД.
:::

## Язык по умолчанию

Только один язык может быть языком по умолчанию (`is_default = true`). Язык по
умолчанию используется как запасной при отсутствии предпочтений пользователя.

Смена языка по умолчанию через UI — переключатель в строке языка. Программно:

```php
Lingua::setDefaultLocale('fr');
```

## Изменение порядка

Перетащите языки за иконку-захват слева от каждой строки. Порядок сохраняется
в поле `sort` таблицы `languages` и отображается в переключателе языков.

## Статистика полноты переводов

Каждая строка языка показывает:

- **Всего строк** — количество строк в `language_lines` (только database-драйвер)
- **Переведено** — строки с непустым значением для данной локали
- **% покрытия** — доля переведённых строк от общего числа

Для детального анализа перейдите на [страницу Statistics](/ru/features/statistics).

Программный доступ к статистике:

```php
$languages = Lingua::languagesWithStatistics();
foreach ($languages as $lang) {
    echo "{$lang->name}: {$lang->completion_percentage}%";
    echo "Missing: {$lang->missing_strings} / {$lang->total_strings}";
}
```

## Управление синхронизацией

Три кнопки синхронизации в панели инструментов (только database-режим):

| Кнопка | Команда | Действие |
|---|---|---|
| **Sync from files** | `lingua:sync-to-database` | Читает все файлы `lang/` и вставляет/обновляет строки в БД |
| **Sync to files** | `lingua:sync-to-local` | Экспортирует все строки из БД в `lang/` в формате PHP/JSON |
| **Update** | `lingua:update-lang` | Загружает новые строки из встроенного набора данных для установленных языков, не затрагивая существующие переводы |

::: tip
Точечное кеширование сбрасывает только затронутый `(locale, group)`, не весь кеш.
:::
