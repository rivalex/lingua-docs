# Статистика

Страница Statistics (`/lingua/statistics`) даёт обзор полноты переводов по всем установленным языкам.

## Общие счётчики

В верхней части страницы — сводные KPI:

| Метрика | Описание |
|---|---|
| **Total languages** | Количество установленных локалей |
| **Total strings** | Общее количество записей в `language_lines` |
| **Translated** | Строки с непустым значением хотя бы для одной локали |
| **Missing** | Строки без значения для активной локали |

## Покрытие по языкам

Таблица покрытия показывает для каждого установленного языка:

| Столбец | Описание |
|---|---|
| Язык | Название и флаг |
| Покрытие | Прогресс-бар с процентом завершения |
| Переведено | Строки со значением для данной локали |
| Отсутствует | Строки без значения — нажмите для раскрытия панели |

Нажмите на строку языка, чтобы перейти на страницу Translations с предварительно выбранной этой локалью и активным фильтром **Show only missing**.

**Язык по умолчанию** всегда показывает 100% покрытие — он определяет эталонный набор ключей.

## Просмотр отсутствующих ключей

Нажмите на **счётчик отсутствующих** в строке языка, чтобы раскрыть панель отсутствующих ключей прямо в строке. Каждая запись показывает группу, ключ и прямую ссылку на редактор.

## Разбивка по группам

Секция «By group» показывает количество строк и процент полноты для каждой группы (`auth`, `validation`, `pagination` и т.д.) отдельно, что помогает приоритизировать работу.

## Переводы пакетов (vendor)

Переключатель **Show vendor translations** включает/выключает вендорные строки (`is_vendor = true`) в счётчиках. Вендорные строки часто заполнены из встроенного набора данных, поэтому их скрытие даёт реалистичную картину покрытия *ваших* строк.

::: tip Database-драйвер
В database-режиме счётчики читаются из таблицы `language_lines` — всегда актуальны.
В file-режиме вычисляются из файлов `lang/` при каждом запросе.
:::
