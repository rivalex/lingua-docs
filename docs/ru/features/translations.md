# Управление переводами

Страница Translations (`/lingua/translations`) — основной рабочий стол для редактирования строк переводов.

## Переключатель локалей

В верхней панели инструментов находится переключатель локалей, который применяет **фильтр активной локали** ко всей таблице. Таблица показывает исходное значение (локаль по умолчанию) слева и редактируемое значение для выбранной локали справа.

## Фильтры

| Фильтр | Назначение |
|---|---|
| **Group** | Фильтрация по группе (`auth`, `validation`, `pagination` и т.д.) |
| **Search** | Поиск по ключу или значению |
| **Show only missing** | Показывать только строки без значения для текущей локали |
| **Show vendor** | Включать переводы вендорных пакетов |

## Пагинация

Управляется ссылками пагинации внизу страницы. Размер страницы ограничен ≤ 100
строк для предотвращения перегрузки интерфейса.

## Встроенное редактирование

Нажмите на любую строку в таблице — откроется встроенная форма редактирования:

- **Тип `text`** — однострочный или многострочный textarea
- **Тип `html`** — rich-text редактор TipTap с кнопками форматирования из конфигурации
- **Тип `markdown`** — редактор TipTap в режиме Markdown

Нажмите за пределами строки или нажмите `Escape`, чтобы закрыть без сохранения.
Нажмите `Ctrl+Enter` / `⌘+Enter`, чтобы сохранить.

::: tip Database-драйвер
Типы `html` и `markdown` доступны только в database-драйвере. В file-драйвере
все строки редактируются как обычный текст.
:::

## Синхронизация из языка по умолчанию

Кнопка **Sync from default** копирует значение для каждого ключа из локали по умолчанию в выбранную локаль — только для строк без перевода. Полезно для начальной загрузки нового языка.

## Модальное окно редактирования

Для более удобного отображения объёмных переводов нажмите иконку разворота в строке. Откроется полноэкранное модальное окно с тем же редактором. В модальном окне для локали по умолчанию можно также изменить **тип** перевода (`text`, `html`, `markdown`).

## Создание переводов

Нажмите **New Translation** в панели инструментов. В форме укажите:

- **Group** — группа (например, `emails`)
- **Key** — ключ (например, `welcome_subject`)
- **Type** — `text`, `html` или `markdown`
- **Value** — значение для текущей локали

Новый ключ сразу становится доступен через `__('emails.welcome_subject')`.

## Удаление переводов

Кнопка удаления в строке таблицы удаляет **всю запись** (все локали).

::: danger Защита вендорных переводов
Вендорные строки нельзя удалить через UI — попытка выбросит
`VendorTranslationProtectedException`. Используйте `setVendorTranslation()` для
переопределения значения без удаления.
:::

## Копирование ключа

Нажмите иконку буфера обмена рядом с ключом, чтобы скопировать строку в формате
`__('group.key')` для вставки в PHP/Blade файлы.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl+Enter` / `⌘+Enter` | Сохранить строку |
| `Escape` | Закрыть редактор без сохранения |
