# 翻译管理

翻译页面（`/lingua/translations`）是编辑翻译字符串的主界面。

## 界面概览

### 工具栏

工具栏包含：

- **语言区域切换器**——选择要查看/编辑翻译的目标语言
- **分组过滤器**——按翻译组筛选（`auth`、`validation`、`pagination` 等）
- **搜索框**——按键名或翻译值搜索
- **仅显示缺失**开关——只显示当前语言区域未翻译的条目
- **包含供应商**开关——显示/隐藏供应商翻译行

### 翻译列表

列表中每行显示：

- **键名**——翻译键（例如 `auth.failed`）
- **默认语言值**——默认语言区域的翻译值（用于参考）
- **目标语言值**——当前选择语言区域的翻译（可编辑）
- **类型标识**——`text`、`html` 或 `markdown`（仅数据库驱动）
- **操作按钮**——从默认语言同步、复制到剪贴板、删除

## 内联编辑

点击任意翻译行进入编辑模式：

- **`text` 类型**：单行或多行文本输入框
- **`html` 类型**：富文本编辑器（工具栏可在 `config/lingua.php` 中配置）
- **`markdown` 类型**：带实时预览的 Markdown 编辑器

按 **Enter**（或点击确认按钮）保存，按 **Escape** 取消。

::: tip 键盘快捷键
- `Enter`——保存并移至下一行
- `Escape`——取消编辑
- `Tab`——移至下一个可编辑字段
:::

## 创建新翻译

点击工具栏中的**新增翻译**按钮：

1. 输入分组（`group`）——例如 `emails`
2. 输入键名（`key`）——例如 `welcome_subject`
3. 输入默认语言的翻译值
4. 选择类型（`text`/`html`/`markdown`）

新翻译会立即创建并可在列表中编辑。

## 从默认语言同步

每行操作菜单中的**从默认语言同步**按钮，会将默认语言的值复制到当前目标语言区域，作为翻译起点。

## 删除翻译

- **删除当前语言区域的值**：仅清除目标语言区域的翻译值（`text` JSON 列中移除该语言键）
- **删除整条记录**：在默认语言区域视图中删除，会删除整行（所有语言区域的值）

::: warning 供应商翻译
供应商翻译行（`is_vendor = true`）不能被删除。尝试删除会抛出 `VendorTranslationProtectedException`。这些行只能被**覆盖**（更新值），不能被删除。
:::

## 分页与筛选

- 每页显示条数可在设置中配置
- 分组、搜索和"仅显示缺失"筛选条件会合并生效
- URL 查询参数会保存当前筛选状态，便于分享链接

## 剪贴板复制

每行末尾的剪贴板图标可复制翻译键或翻译值。适用于快速在代码中引用翻译键。
