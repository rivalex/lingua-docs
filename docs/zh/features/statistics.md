# 翻译统计

统计页面（`/lingua/statistics`）实时展示所有已安装语言的翻译覆盖率。

## 概览计数器

页面顶部显示全局统计数据：

- **已安装语言**——`languages` 表中的语言总数
- **总翻译键数**——`language_lines` 表中的行总数
- **已翻译**——在默认语言区域中有值的键数量
- **总体覆盖率**——所有语言的平均翻译完成度

## 按语言覆盖率

主表格按语言显示翻译完成度：

| 列 | 说明 |
|---|---|
| 语言 | 语言名称和国旗图标 |
| 总数 | 该语言应有的翻译总数 |
| 已翻译 | 有实际值的翻译数量 |
| 缺失 | 尚未翻译的数量 |
| 完成度 | 进度条（绿色=完成，红色=缺失） |

点击语言行可展开，查看该语言中**缺失键的按分组明细**。

## 缺失键钻取

展开某语言行后，显示按翻译分组（`auth`、`validation`、`pagination` 等）统计的缺失键列表：

```
▼ French (fr)    85% 完成    缺失 42 个
  auth            0 / 5     ████████ 完成
  validation      38 / 42   ████░░░ 部分完成
  pagination      0 / 4     ████████ 完成
  ...
```

点击分组名称可直接跳转到翻译页面，并预设该语言区域+分组的筛选器，方便立即开始翻译。

## 按分组分解

第二个视图按**翻译分组**（而不是语言）显示完成度：

- 列出每个分组（`auth`、`validation`、`passwords` 等）
- 显示每种语言在该分组中的完成度

## 供应商翻译切换

右上角的**包含供应商**开关控制统计数据是否包含 `is_vendor = true` 的行。

关闭时：只统计您自己的翻译键，更准确地反映您内容的完成度。
开启时：包含所有 Laravel 核心和第三方包的翻译字符串。

## 数据来源

统计数据通过 Eloquent 查询 `language_lines` 表实时计算，**不**缓存（每次页面加载时重新计算）。对于有大量翻译键（10,000+）的应用，统计页面的加载可能稍慢。

::: tip 文件驱动中的统计
文件驱动模式下，统计页面通过遍历 `lang/` 目录中的 PHP 和 JSON 文件来计算统计数据，而不是查询数据库。
:::
